# boss_sentinel 腐朽守門騎士：v3 規格表

> 分析師 1 產出。參考圖：`art/reference/v2/sentinel_p1.jpg`（一階，3/4 視角）、`sentinel_p2.jpg`（二階，近正面，**身體比例主要量這張**，沒有門板遮擋）。遊戲身高 H = 3.1 m（斗笠頂到腳底）。
> 和 `art/v2/art_guide.md` 衝突時以這份為準（量測值已重新校正）。

## 最重要的 5 件事
1. **斗笠改形**：參考圖是「平寬圓盤＋中央低圓頂冠」，不是斗笠錐。直徑 0.36H（現在約 0.45H，太大 25%），簷面只往下傾 8–12°。
2. **手臂前段要粗**：前臂外輪廓（含護臂）0.085H、鐵手套袖口 0.10H、拳寬 0.075H。現在前臂只有約 0.055H，細了 35%，看起來像細竹竿插在大肩甲下。
3. **顏色降飽和**：參考圖是「暗槍鐵灰褐＋暗橄欖苔」，不是紅鏽＋螢光綠苔。鏽斑只長在縫隙、鉚釘周圍和下緣；苔是暗橄欖色 #3a3d26，不要用 #4f8a2a 那種亮綠。
4. **布與根要「破」**：長擺用多層厚亞麻，有厚度、破洞、縱向撕條，條長不能一樣；全身垂很多細根鬚（直徑 0.004–0.01H），讓輪廓毛起來。現在的長擺是平板切條，根也太少、太粗、太規整。
5. **壓迫感姿勢**：Idle 時雙腳中心距 0.26–0.30H、膝微彎、上身前傾 8–10°、頭略低，讓笠簷遮住上半臉。戟斜指地面，門板背在背後並偏左肩 10–15°。

## 3. 表面細節清單（法線貼圖必須看得到）
1. 所有板甲的錘痕（細點狀凹凸，直徑 0.01–0.02H）＋ 3–8 個較大的凹痕（直徑 0.015–0.03H）。
2. 板甲翻邊（rolled edge）和疊片邊緣的倒角高光。
3. 鉚釘：肩甲、護喉、裙甲、門板框、手套；有半球凸起，周圍一圈鏽暈。
4. 斗笠盤面的同心旋壓紋，加上金帶邊緣的段差。
5. 刮痕：胸甲 1 條長的、全身 10–20 條短的（長 0.01–0.03H）。
6. 鏽蝕起泡：鏽斑區要有粗糙顆粒和剝落邊。
7. 長擺的粗麻織紋（經緯可辨）、撕裂邊的纖維毛邊、破洞邊緣捲起。
8. 皮帶的龜裂皺紋和邊緣縫線。
9. 門板木紋、乾裂、板縫、腐爛缺角的纖維，鐵框壓進木頭的凹陷。
10. 苔蘚顆粒高度（不能只是平的綠色塊）。
11. 根鬚樹皮的縱紋和節瘤。
12. 鎖子甲的環（用貼圖重複，要看得出環形）。
13. 戟刃的缺口、刃口磨痕和鏽坑。

## 4. 壓迫感要點
- **剪影**：從上往下依序是寬盤笠（0.36H）、厚肩（0.34H）、直筒身（腰不收）、寬站的雙腿、毛邊的長擺下緣。背後門板從兩肩外側各露出 0.03–0.05H，從正面看會讓肩更寬。
- **重心**：低。膝彎 10–15°，雙腳寬站 0.26–0.30H，重心在兩腳中間偏前。
- **姿勢（Idle）**：上身前傾 8–10°，頭再低 5°，讓笠簷蓋住到眼睛以下，只看得到兩點光。持戟手垂在身側，戟頭斜指前下方地面（和地面約 30°）。空手（左手）微握拳、離身體 0.05H。
- **誇大厚重**：肩甲、鐵手套、鐵靴、門板厚度。前臂和小腿不能比上臂和大腿細太多（目測粗細差 ≤ 15%），才有「全身包鐵」的感覺。
- **毛邊輪廓**：根鬚、苔條、長擺撕條讓輪廓不乾淨，這是「腐朽」的關鍵。
- **門板位置**：照 design.md 背在背後直立，但往左肩偏 0.04H、順時針傾 10–15°，接近 p1 的斜角剪影。門板頂部比肩高 0.05–0.08H，從正面要看得到頂角露出。

## 7. 審查量測方法
1. **姿勢**：在 rest pose（所有骨頭歸零）量比例；Idle 第 0 格另外量站距、前傾角。
2. **身高**：不含 `P2_*`、`P3_*` 和輔助物件（例如 `Icosphere`），所有可見 mesh 頂點的 z 最大值減最小值 = H。
3. **水平截面**（頂點落在 z = h·H ± 0.006H 的帶狀範圍內，沿 x 分群，群間距 > 0.012H 就算不同群）：
   - 0.90H：斗笠直徑（x 和 y 都要量），目標 0.36H ±10%
   - 0.82H：肩外寬，目標 0.34H
   - 0.71H：胸寬／胸厚（排除門板：只取 y < 門板內側的頂點）
   - 0.58H：腰寬／腰厚
   - 0.50H：臀寬
   - 0.38H、0.28H、0.18H、0.08H：大腿、膝、小腿、腳踝（單腿分群）
4. **肢體截面**：沿骨頭方向，在上臂、前臂、大腿、小腿的 t = 0.5 處取垂直骨頭的截面（±0.01H），量兩個方向的寬度。**前臂 ≥ 0.077H 才算通過**（0.085H −10%）。
5. **武器**：沿 `Weapon` 骨到 `Tip_Weapon` 的直線，量 0.02H 半徑內頂點的投影範圍 → 全長 0.80H；斧刃量垂直桿方向的最大距離 → 0.10H。
6. **門板**：取背後 y 方向的頂點，量 bounding box：高 0.62H、寬 0.31H、厚 0.035H。
7. **並排渲染**：
   - 視角 A：正面略俯（相機高 0.6H、仰角 −5°），對 `sentinel_p2.jpg`（顯示 P2 部件）。
   - 視角 B：3/4 視角，相機在角色右前方 35°，對 `sentinel_p1.jpg`。
   - 光：左上主光＋弱冷色補光，背景 #3a3a38，曝光讓甲面落在 #40–#70 灰階。
   - 縮到同樣高度並排，檢查：斗笠盤形、肩寬、手套與靴的厚度、長擺層次、顏色飽和度。
8. **材質抽查**：近拍（相機距離 0.3H）肩甲、長擺下緣、門板下角、戟頭 4 張，確認錘痕、織紋、木紋、鏽坑在法線上看得到；並比對 R/M 值和表 2 一致（布 ≥ 0.9、甲 0.45–0.75）。
