# hero_knight 主角騎士：v3 規格表

> 分析師 1 產出。參考圖：`art/reference/hero_knight_sheet.jpg`（左：正面 A-pose，劍尖拄地；右：左側面）。遊戲身高約 1.8 m（現有模型 1.817 m，維持不變）。
> 節點合約：現有 GLB 的骨頭是 Root、Hips、Spine、Spine2、Neck、Head、Shoulder/UpperArm/Forearm/Hand ×L/R、`Weapon`、`Cape1`–`Cape3`、Thigh/Shin/Foot ×L/R，**沒有 `Tip_Weapon` 節點**，名稱全部照舊。動作片段：Idle, Walk, StrafeL, StrafeR, Run, Slash, HeavySlash, Combo, Roll, DodgeBack, Parry, Guard, Hit, HitHeavy, Cast, Die, Victory。

## 最重要的 5 件事
1. **頭盔縮小並改形**：寬 0.10H、深 0.13H、高 0.145H，頂上有中脊，面罩往前突成鈍尖（側面看像船頭）。現在是圓桶，寬 0.129H，大了 29%，看起來像大頭娃娃。
2. **軀幹要加上布和皮**：參考圖的胸口被一件**破舊的灰藍亞麻罩袍（tabard）**蓋住，下擺破到 0.37H；外加一條斜背帶（右肩到左腰）、兩條腰帶、右胯皮袋、左胯劍鞘。現在模型是光禿禿的胸甲，加上大片鏽。
3. **鋼要是灰的**：參考圖的鋼是霧面鋼灰 #8a8c88，只在縫隙和凹處有褐色污垢；現在到處都是橘紅鏽斑，變成另一個角色。
4. **左右肩甲不對稱**：左肩是一片大圓肩甲（0.13H 寬，有直立護頸翼），右肩是 4 片疊甲。上臂、肘內側、頸部、罩袍下的大腿要露出**鎖子甲**。
5. **披風是厚羊毛**：深藍、霧面（R 0.9），先在肩上繞成圍巾狀並用圓環別針別住，再往後垂到 0.13–0.20H，下緣破爛、有縱向皺褶和厚度。現在的披風是有光澤的薄片，上面開了幾個方洞。

## 3. 表面細節清單（法線貼圖必須看得到）
1. 板甲翻邊（rolled edge）和疊片邊的倒角。
2. 鉚釘（肩甲邊緣、面罩轉軸、疊片、皮帶扣）。
3. 刮痕和小凹痕（頭盔、胸甲、膝甲、肩甲）。
4. 頭盔的中脊稜線、透氣孔、視縫。
5. 鎖子甲的環（頸、上臂、肘內、腿）。
6. 罩袍亞麻織紋、撕裂毛邊、小破洞。
7. 披風毛料的絨感和粗織紋、下緣破邊。
8. 皮帶縫線、龜裂、邊緣磨損；皮袋皺褶。
9. 劍柄纏皮紋、劍身血槽、刃口缺口。
10. 靴子鐵疊片的段差和皮革皺褶。

## 4. 壓迫感要點（主角版：沉穩、可信，不是可愛）
- **剪影**：小頭、寬肩（左大右小）、直筒軀幹、披風在背後形成一片深色大面、劍尖拄地。
- **比例**：頭盔寬只有肩寬的 29%。現在的頭盔是肩寬的 37%，所以看起來偏 Q 版。
- **重心**：Idle 時雙腳 0.18–0.21H 寬站、膝微彎 5°、雙肩略往前收；劍握在右手，劍尖朝下前方。
- **厚重感**：肩甲、手套袖口、膝甲、靴要比肢體明顯厚；披風要有實體厚度，下緣碰到小腿。
- **舊**：罩袍、披風、皮件都看得出長途旅行的磨損，但金屬本身是保養過的灰鋼（不要鏽成紅色）。

## 7. 審查量測方法
1. rest pose 量比例；Idle 第 0 格另外量站距、劍的位置；Guard 和 Roll 的時候檢查披風和劍鞘有沒有穿過腿。
2. H = 所有可見 mesh 頂點的 z 範圍（不含 `Icosphere` 之類的輔助物件）。
3. **水平截面**（z = h·H ± 0.006H，沿 x 分群）：
   - **0.93H：頭盔寬 0.10H、深 0.13H**（重點）
   - 0.80H：肩外寬 0.35H
   - 0.73H：胸寬／胸厚（排除披風：只取 y < 背部 + 0.01H 的頂點）
   - 0.60H：腰寬
   - 0.52H：臀寬
   - 0.40H、0.30H、0.20H、0.08H：大腿、膝、小腿、腳踝（單腿）
   - 0.01H：腳長 0.15H
4. **肢體截面**：上臂、前臂在 t = 0.5、手腕在 t = 0.95，垂直骨頭量兩個方向。
5. **劍**：`Weapon` 骨附近（劍 mesh）的 bounding box 長軸 → 0.60H；護手長 0.13H。
6. **並排渲染**：
   - 視角 A：正面，相機高 0.55H、焦距 50mm 等效，對參考圖左人物。
   - 視角 B：左側面（相機在角色左邊，角色面向畫面左），對參考圖右人物。
   - 光：柔和頂光＋淺灰背景 #c8c8c8（模仿參考圖的棚拍），再另外拍一張暗場（遊戲背景）確認輪廓可讀。
   - 檢查：頭肩比、罩袍和披風的層次、左右肩不對稱、鋼的灰度（亮部 #8a–#b0）。
7. **材質近拍**：頭盔、左肩甲＋圍巾別針、罩袍下緣＋鎖子甲、靴各一張，相機距離 0.3H。
