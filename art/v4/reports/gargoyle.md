- 既有 17 個片段的名稱、時長、hits 完全沒變：新舊 `export_raw/boss_gargoyle.clipmeta.json` 逐項比對過。
- 模型沒有重建。這次只重跑 `anim` 階段，重用 `source/v2a_boss_gargoyle_model.blend` 的烘焙結果，所以外觀和型態部件都沒變：
  - 51 個節點，39,445 面。
  - 5 個材質。
  - 4 張貼圖，位元組大小和舊版相同。
  - 8 個 `P2_*` 節點，scale 0／hiddenByDefault 照舊。

- 已跑 `merge_clipmeta.py`。

### 防滑步（已知問題「前爪會滑」）
- 新片段的前肢改用 IK，烘成 FK 關鍵格。`Hand.L/R:ik` 是相對靜止手腕位置的偏移，偏移 0 代表釘在地上。
- 爪子要換位置時，一律先抬起、再落下踩步，不在地上拖。後腳沿用原本的 `Foot:ik`。
- 量測方式：逐格看爪尖和腳趾，兩格都低於 6 cm 時算水平位移。
  - 新片段每格最大位移在 1–4 cm，只出現在抬爪或落地那一格，是起步推地的動作。
  - 既有片段最大位移 12–68 cm/格，例如 Dash 的 Fingers.R 是 68 cm。
- 既有片段的滑步這次沒有修：不能動既有片段。

### Sweep（石翼橫掃，一階）
- **動作**：
  1. 左前爪往外踏寬撐地。
  2. 身體往左後扭，左翼保持立起，往後拉滿到身後；右翼高舉平衡，頭轉回來盯著主角。
  3. 0.9 s 右爪推地：身體猛甩向右，左翼像一面石牆從左後方水平掃過正前方，甩到右側。
  4. 尾巴反向甩開，兩爪踩回原位。
- **和既有招式的差別**：Attack 是右爪由上往下砸，Attack2 是尾鎚過肩。這招是唯一一招「水平、翅膀當武器」的大範圍掃擊，節奏是「長拉—一甩」。
- **特效／音效建議**：

  | 時間 | 建議 |
  |---|---|
  | 0.27 s | 爪落地，石頭腳步聲 |
  | 0.45–0.8 s | 石翼拉緊，石頭摩擦、低吼 |
  | 0.9 s | 破風聲起 |
  | **1.0 s** | 命中：沉重的翼掃破風＋石塊撞擊；水平弧形刀光（Boss 左後→右前，高度約胸口），翼緣甩出碎石屑 |
  | 1.17 s | 尾巴甩，咻聲 |
  | 1.93 s | 爪落地 |

### Smash（俯衝砸地，二階）
- **動作**：
  1. 深蹲，雙翼高舉。
  2. 0.8 s 振翼下拍拔地躍起。
  3. 1.03–1.27 s 在空中滯空：後腿收起、雙爪高舉、仰身，雙翼張到最大。這是最清楚的預備姿勢。
  4. 1.47 s 收翼，頭朝下俯衝。
  5. **1.567 s** 雙爪和胸口一起砸進前方約 0.85 m 的地面，翅膀往前下方拍地，尾巴高翹。
  6. 壓縮停頓後抬頭，前後爪依對角順序踩回原位。
- **和既有招式的差別**：Delayed 是原地立起停頓再砸。這招整隻離地，從空中往前下方俯衝，是本 Boss 唯一的「空中→地面」招。
- **特效／音效建議**：

  | 時間 | 建議 |
  |---|---|
  | 0.6 s | 雙翼高舉，石翼展開聲 |
  | 0.8 s | 起跳：地面塵土環＋重拍翼聲 |
  | 1.0 s、1.27 s | 空中各拍一次翼 |
  | 1.47 s | 俯衝破風 |
  | **1.567 s** | 命中：重砸地，鏡頭大震；地裂環、碎石彈起、煙塵 |
  | 2.33 s | 抬頭低吼 |
  | 2.5 / 2.77 s | 兩次踩步 |

### Leap（飛撲，二階突進）
- **動作**：
  1. 身體後坐，雙翼往後上方收起，像鷹準備撲擊；尾巴左右甩。
  2. 0.87 s 後腳一蹬，雙翼下拍。
  3. 整隻離地往前飛撲約 1.3 m，雙前爪張開往前伸。
  4. **1.167 s** 雙爪同時壓地，就是把主角撲倒的位置。翼往上張開煞車，張口低吼。
  5. 2.03–2.2 s 振翼往後跳回原位落地。
- **和既有招式的差別**：Dash 是右爪單手掃、身體只前探 0.6 m。這招四肢離地、雙爪同時按地，而且有後跳脫離。
- **特效／音效建議**：

  | 時間 | 建議 |
  |---|---|
  | 0.3–0.7 s | 喉音低吼、尾巴抽地 |
  | 0.87 s | 蹬地塵土＋翼下拍 |
  | 0.9–1.15 s | 飛撲破風，殘影可選 |
  | **1.167 s** | 命中：雙爪按地重擊、塵土；肉／甲受擊聲 |
  | 1.67 s | 壓制咆哮 |
  | 2.03 s | 後跳翼拍 |
  | 2.4 s | 落地 |

### ComboB（撕咬連擊，二階三連）
- **節奏**：慢—快快，和 Combo3 的快快—慢相反。三下之間隔 0.6 s 和 0.2 s。
- **動作**：
  1. 第一口（長預備）：頸往後縮，頭往右上抬，嘴張到最大，雙翼半舉。**0.867 s** 整個上身往前猛咬，雙前爪各踏前一步。接著往後撕扯、甩頭。
  2. 第二口：頭甩到左邊張口，**1.467 s** 往右快咬，右翼跟著往前包。
  3. 第三口：馬上反向往左上方再咬一口，**1.667 s**，咬得更深，左翼往前包。
  4. 咬住後左右甩頭兩次，兩爪依序退回。
- **特效／音效建議**：

  | 時間 | 建議 |
  |---|---|
  | 0.33–0.8 s | 張嘴嘶聲，P2 熔光嘴發亮 |
  | **0.867 s** | 命中 1：重咬合「喀」＋肉／甲撕裂聲，嘴前半月形咬痕特效 |
  | **1.467 s** | 命中 2：快速咬合 |
  | **1.667 s** | 命中 3：快速咬合 |
  | 1.87–2.2 s | 甩頭撕扯，碎屑或火星 |
  | 2.63 / 2.9 s | 踩步 |

### Special（碎石吐息，二階必殺）
- **動作**：
  1. 0–0.47 s 半立起，前爪離地抬到胸前，雙翼張到最大，頭仰起。
  2. 0.8 s 雙翼往前一兜，像在把空氣攏進胸口。頭仰天、嘴開合「吸氣」。
  3. 1.07–1.8 s 雙翼再展到最開，全身蓄力顫抖。這是最長、最有威脅的預備。
  4. 1.93 s 雙爪重重砸地撐住，低頭，嘴張到最大。
  5. **2.033 s** 吐息開始（命中 1），一直持續到約 3.1 s。
     - 頭從 Boss 的右邊慢慢掃到左邊，從主角的角度看是從左掃到右。
     - 身體被反作用力往後推，雙翼往後張開抵住。
  6. 3.17 s 頭縮一下。
  7. **3.367 s** 往前猛吐最大的一口（命中 2）。
  8. 閉嘴甩頭，前爪依序退回。
- **特效／音效建議**：

  | 時間 | 建議 |
  |---|---|
  | 0–0.47 s | 立起時石頭摩擦聲 |
  | 0.8 s | 吸氣聲＋粒子往嘴裡吸，胸口／石縫熔光漸亮 |
  | 1.07–1.8 s | 低頻隆隆聲、全身顫抖；嘴裡熔光越來越亮（Glow 倍率往上拉），地面小碎石震動 |
  | 1.93 s | 爪砸地 |
  | **2.033 s** | 命中 1：碎石吐息開始。燒紅碎石錐形噴流，從嘴部往前並跟著頭轉向；持續噴流音（碎石＋火焰嘶聲）到 3.1 s |
  | 3.17 s | 吸一口氣的短停 |
  | **3.367 s** | 命中 2：最大一波爆發（碎石量×2、鏡頭震、黑煙） |
  | 3.73 s | 噴流收尾、閉嘴 |
  | 4.17 / 4.43 s | 踩步 |

  可以沿用 vfx 報告裡現有的「碎石吐息」特效：約 40 顆燒紅碎石，分 4 波＋黑煙。

## 已知問題
- 既有片段（Attack、Dash、Combo3 等）的前爪滑步和 −9 到 −15 cm 穿地還在，因為合約不准動既有片段。如果之後允許，可以用同一套前肢 IK 重做。
- 新片段剩下 −4 到 −5 cm 的穿地，都是手腕斷鏈的末端（剛性跟著前臂轉）。要再改善，得把鏈子末端改綁到 Hand 骨，屬於建模，這次不做。
- 爪子抬起和落地那一格有 1–4 cm 的水平移動，是起步推地的動作，不是站著滑。
- 頭部命中用的是 Head 骨尾端（吻部）的速度峰值。Special 吐息是持續招，命中 1 只是開始時間；如果判定要持續，請用 2.033–3.1 s 當持續區間。
