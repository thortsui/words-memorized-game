# 第三方資源（掃描上傳用到的）

2026-11-26 整理。這裡只列「掃描上傳」功能用到的外部資源；戰鬥用的 three.js 與模型不在這份清單內。

全部都是**免金鑰、免費、在瀏覽器本機執行**的：照片不會上傳到任何伺服器。模型檔與執行檔第一次用到時才從 CDN 下載，之後存在瀏覽器裡（Cache Storage／IndexedDB），離線也能用。

| 檔案 | 內容 | 來源 | 授權 |

| `public/wordlist/en-names.txt`（136 KB，16,572 個） | 專有名詞表（人名、地名），例句裡的 Mary、Taiwan 不會被當成拼錯。 | SCOWL 2020.12.07 官方壓縮檔（<http://wordlist.aspell.net/>，SourceForge 下載）的 `*-proper-names.*` 與 `*-upper.*` 清單，等級 ≤70，只留「大寫開頭＋小寫字母」的字，存成小寫。 | 同上（SCOWL）。 |
| `public/wordlist/SCOWL-Copyright.txt` | SCOWL 的著作權與授權聲明原文（授權條件要求隨附）。 | SCOWL 2020.12.07 的 `Copyright` 檔。 | — |

重建詞表的方法：`npm pack wordlist-english@1.2.1` 解開後，把 `english|american|british|canadian|australian-words-{10,20,35,40,50,55,60}.json` 合併、轉小寫、只留 `[a-z']`、去重複排序。等級 70 以上的冷僻字刻意不收：詞表越大，拼錯的字剛好是另一個冷僻字的機會越高。

- 沒有用任何第三方的 PaddleOCR JavaScript 套件：偵測後處理（機率圖→連通區塊→外接矩形→擴張）與辨識的 CTC 解碼直接寫在 `src/scan/engines/ppocr.js`，參數照官方 `inference.yml`（thresh 0.2、box_thresh 0.45、unclip_ratio 1.4）。
- 調查過但沒採用的套件：官方 `@paddleocr/paddleocr-js@0.4.2`（Apache-2.0，連 OpenCV.js 共 23 MB，偏重）、`esearch-ocr`、`@gutenye/ocr-browser`、`ppu-paddle-ocr`、`paddleocr`（都可用，但各自綁模型來源與快取方式，不好控制離線快取）。
- Hugging Face 的 `resolve/` 網址有開 CORS（`Access-Control-Allow-Origin` 回應來源網域），瀏覽器可以直接抓。
- 參考：PP-OCRv6 技術報告 <https://arxiv.org/abs/2606.13108>。

## 選用、預設不啟用

- **Claude API**（`src/scan/engines/claude.js`，模型 `claude-opus-5-5`）：要使用者自備 Anthropic API 金鑰，依用量向使用者的帳號收費，照片會送到 `api.anthropic.com`。收在上傳頁「進階（需自備金鑰、會計費）」的摺疊區裡，沒有勾選啟用就不會出現在引擎選項、也不會提示輸入金鑰。

## 快取位置

| 內容 | 存在哪裡 |
| --- | --- |
| onnxruntime-web、PP-OCR 模型與字元表、tesseract.js 的程式檔 | Cache Storage，名稱 `vc-scan-models-v1`（`src/scan/cache.js`） |
| tesseract 語言資料 | IndexedDB（tesseract.js 自己管理） |
| 英文詞表、專有名詞表 | 同一個 Cache Storage（第一次核對時從網站本身載入） |

Cache Storage 只在 https 或 localhost 可用；用 `file://` 或一般 http 開啟時會退回每次重新下載，功能不受影響。清除瀏覽器的網站資料會把這些都清掉，下次使用再下載一次。
