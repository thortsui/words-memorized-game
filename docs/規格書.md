# 單字剪卡 規格書

2026年11月26日 · @Ethan Tsui

> 這是原始單檔版（`單字剪卡.html`）的規格書，整理成 Markdown 留存。
> 目前的專案已改成 Vite 多檔模組，戰鬥畫面改由 3D 場景呈現；與本規格不同之處記在文末「改版差異」。

## 1. 產品概觀與技術架構

單字剪卡是一個單一 HTML 檔的英文單字學習工具：拍單字書照片建立字典，再用五種題型與兩種戰鬥遊戲練習。照這份規格可重建功能相同的版本。

| 項目 | 規格 |
| --- | --- |
| 交付形式 | 一個 .html 檔（約 650 KB），CSS、JS、圖片（base64 WebP）全部內嵌，用 Chrome 直接開啟 |
| 框架 | 無。原生 JavaScript，畫面以字串模板寫入 `#app` |
| 字型 | Google Fonts：Lexend（英文）、Noto Sans TC（中文） |
| 路由 | `location.hash`：`#dicts`、`#dict-<id>`、`#upload`、`#practice`、`#history` |
| 儲存 | localStorage，可匯出／匯入 JSON 備份 |
| 外部連線 | Google 翻譯語音與翻譯（非官方端點）、Anthropic API（選用）、tesseract.js 與 jsPDF（CDN，用到才載入） |
| 離線可用 | 練習、戰鬥、裝置語音。提取單字、Google 語音、PDF 需連線 |

### 頁面

| 頁面 | 內容 |
| --- | --- |
| 字典 | 字典卡片（條目數、錯題數）、練習、瀏覽編輯、新增空白字典、匯出／匯入備份 |
| 字典內頁 | 搜尋、逐筆朗讀、編輯、刪除、新增單字、重新命名、刪除字典 |
| 掃描上傳 | 選照片、調四角、掃描、提取、核對、存入字典、下載掃描 PDF、手動貼上 |
| 練習 | 選字典、玩法、題型、範圍、題數、例句模式、發音設定 |
| 錯題紀錄 | 每字錯幾次、何時、答了什麼；練習歷程；一鍵練待複習 |

### 視覺主題

一般頁面模仿單字書的剪卡：白底、虛線邊框、剪刀圖示、灰色直排側標、橘紅色（`#dc4f22`）單字。支援亮色與暗色。

## 2. 資料模型

所有資料存在 localStorage 的 `vocab-cards-v1` 一個 JSON 物件裡，匯出備份就是這個物件。

```json
{
  "dicts": { "<dictId>": { "id": "", "name": "", "words": [Word] } },
  "miss":  { "<dictId>": { "<wordId>": 1 } },
  "wlog":  { "<dictId>": { "<wordId>": { "n": 3, "last": 0, "ans": [{ "a": "", "m": "en2zh", "t": 0 }] } } },
  "hist":  [{ "t": 0, "mode": "en2zh", "dict": "", "n": 10, "right": 8, "wrong": [["dictId", "wordId"]], "game": false }],
  "hidden": { "no307": true },
  "t": 0
}
```

| 欄位 | 說明 |
| --- | --- |
| Word | `{id, en, pos, zh, ex, blank, unit}`。`blank` 是例句中實際出現的字形（如 dye 的例句是 dyed），克漏字用 |
| miss | 待複習計數：答錯 +1，答對 -1，歸零即移除 |
| wlog | 永久錯題紀錄：次數、最後時間、最近 5 次錯誤答案（含題型） |
| hist | 練習歷程，最多 80 筆；`game` 為 `false`、`true`（打怪）或 `"soul"`（魂系） |
| hidden | 內建字典被刪除時的標記 |

### 內建字典

內建字典 `no307` 寫死在程式裡（128 筆：96 個單字、32 個片語，來自單字書 p.77–80）。使用者第一次編輯它時，複製一份到 `dicts.no307` 再改。

> 註：原始碼中的資料實際是 95 個單字、33 個片語（合計 128 筆）。移植時以原始碼為準。

### 其他 localStorage 鍵

| 鍵 | 用途 |
| --- | --- |
| `vc-setup` | 練習設定：`{dict, mode, scope, n, wrong, auto, exmode, game}` |
| `vc-eng3`、`vc-voice`、`vc-rate` | 聲音模式（auto／device／google）、裝置聲音名稱、語速（0.9 或慢速 0.65） |
| `vc-bgm`、`vc-story` | 配樂開關、序章是否看過 |
| `vc-ext`、`vc-key` | 提取方式（claude／ocr）、Anthropic API 金鑰 |

## 3. 掃描上傳與單字提取

照片經過「拉平、去陰影、提取、核對、人工確認」五步才存入字典。

1. **載入照片**：可多選；長邊縮到 2400 px 畫到 canvas。
2. **調四角**：畫面疊一個四邊形，四個角可拖曳（預設內縮 2%）。
3. **掃描**：
   - 透視校正：由四角解 3×3 單應矩陣（8 元線性方程），雙線性取樣，輸出長邊最多 2000 px。
   - 去陰影：每 16 px 一格取最大亮度當背景，先做一次 3×3 最大值、再做三次 3×3 平均；每個像素除以內插後的背景亮度，再把 35–232 拉伸到 0–255。
4. **提取**（二選一）：
   - Claude：把掃描圖切成上下兩半（各佔 56% 高度，有重疊），連同提示詞送 `POST https://api.anthropic.com/v1/messages`（標頭含 `anthropic-dangerous-direct-browser-access: true`），要求只回傳 JSON 陣列 `[{en,pos,zh,ex,blank,unit}]`。
   - 免費 OCR：tesseract.js 5.1.1，語言 `eng+chi_tra`，用規則式解析「英文＋詞性＋中文」開頭的行，後續英文行併為例句。
5. **核對**：每筆自動檢查，最多 4 筆同時進行。
6. **人工確認**並存入新字典或既有字典。

### 核對規則

| 檢查 | 判為可疑的條件 |
| --- | --- |
| 空欄位 | 英文或中文是空的 |
| 例句對不上 | 單字（非片語）在例句中找不到對應字形 |
| 例句混到中文 | 例句含中日韓字元 |
| 英文怪字元 | 含英文字母、空格與常用符號以外的字元 |
| Google 不認得 | Google 翻譯回傳內容沒有中文 |
| 中文對不上 | 去掉停用字後，書上中文與 Google 翻譯結果沒有共同字；或書上 ≥4 字而共同字 <2 且比例 <20% |

Google 翻譯端點：`https://translate.googleapis.com/translate_a/single?client=gtx&sl=en&tl=zh-TW&dt=t&dt=bd&q=…`。

可疑條目顯示紅框、原因與 Google 的翻譯，並提供「改好了，重新檢查」與「我確認沒問題」。連不到 Google 時標成「請自己確認」。存入時若還有未確認的可疑條目，要再問一次。

### 其他

- 已存在於任何字典的英文以橘框標示。
- 手動貼上格式：每行 `英文 | 詞性 | 中文 | 例句`。
- 掃描結果可用 jsPDF 2.5.1 輸出成 PDF，每頁一張圖。

## 4. 練習模式

五種題型共用同一套出題、判分與錯題紀錄，一般練習、打怪、魂系三種玩法都用它。

| 代號 | 題型 | 題目 | 作答 |
| --- | --- | --- | --- |
| `en2zh` | 英翻中・選擇 | 英文 | 4 選 1 中文 |
| `zh2en` | 中翻英・選擇 | 中文 | 4 選 1 英文 |
| `en2zhT` | 英翻中・填空 | 英文 | 輸入中文 |
| `zh2enT` | 中翻英・填空 | 中文＋首字母與字母數提示 | 輸入英文 |
| `cloze` | 克漏字 | 例句挖空＋中文提示 | 4 選 1 字形 |

### 出題

- 範圍：單字＋片語、只有單字、只有片語；可勾「只練錯題」。題數 10、20 或全部。
- 片語的判定：詞性含「片語」或英文含空格。
- 干擾選項：從所有字典取 3 個，先限同為單字或同為片語，同詞性的夠 3 個就只用同詞性。
- 克漏字答案：優先用 `blank`；沒有時，取例句中以該字前段（長度減 2，至少 3 個字母）開頭的字。找不到答案的條目不出克漏字。

### 判分

- 輸入英文：轉小寫，去掉 sb、sth、N.、V-ing 等文法標記與符號後比對；`see/regard` 這類斜線寫法，任一個都算對。
- 輸入中文（依序，任一成立即算對）：
  1. 與書上任一義項相同或互相包含（義項以「、；，」切開，括號內容不計）。
  2. 與書上義項的共同字佔輸入的一半以上。
  3. 與 Google 翻譯該英文的任一結果相符（同上兩條規則）。
  4. 把輸入翻回英文，結果包含該單字的字幹。
  - 第 2–4 條成立時顯示「意思相近，算對」。Google 查詢逾時 3.5 秒即略過。
- 填空被判錯時提供「我其實答對了」按鈕，可撤銷這次錯誤。

### 作答後

- 顯示正確答案、詞性、中文、例句，並依序朗讀英文、中文、例句；朗讀完「下一題」才可按。
- 答錯的題目加到本輪最後再考，標示「剛剛答錯，再考一次」，每字最多重出 3 次。
- 成績只算第一次作答；重出的次數與答對數另外顯示。

### 例句模式（預設關閉）

開啟後題目下方顯示英文例句、不附中文。英翻中題把該字標成橘色並可朗讀；中翻英題把該字挖成「?」且不提供朗讀。

### 錯題紀錄頁

列出每個答錯過的字：錯幾次、上次時間、最近答過什麼、待複習或已練會；可依錯最多、最近、待複習排序。下方是練習歷程，點開看該次錯的字。「練習待複習的 N 個」直接開始只含這些字的練習。

## 5. 朗讀系統

朗讀預設先用瀏覽器內建語音，失敗才改用 Google 翻譯語音，因為後者是非官方端點、常被限流。

| 聲音模式 | 引擎順序 |
| --- | --- |
| 自動（預設） | 內建語音 → Google 翻譯語音 |
| 只用裝置語音 | 內建語音 |
| Google 翻譯語音優先 | Google 翻譯語音 → 內建語音 |

### 內建語音（Web Speech API）

- 英文 en-US，聲音優先序：Google US English、Premium／Enhanced、Natural、Siri、Samantha、Ava；使用者可自選。
- 中文 zh-TW，優先「Google 國語（臺灣）」，其次任何 zh-TW、zh-HK、zh 聲音。
- 不依賴 `onend` 事件（Chrome 常不觸發）：每 200 毫秒檢查 `speechSynthesis.speaking`。
- 2.5 秒內沒開始視為失敗；單句上限 20 秒；`cancel()` 後等 90 毫秒再 `speak()`。
- 把 utterance 存進陣列，避免被回收。

### Google 翻譯語音

- 端點：`https://translate.google.com/translate_tts?ie=UTF-8&client=tw-ob&tl=<en-US|zh-TW>&q=…`，備用主機 `translate.googleapis.com`（`client=gtx`）。
- 用單一 Audio 元素播放；超過 180 字元依標點切段。
- 2.5 秒沒開始播、或播放中 4 秒沒進度：換另一個主機試一次，再失敗就交給下一個引擎。
- 頁面加 `<meta name="referrer" content="no-referrer">`。
- 不預先載入音檔（會加倍請求量而被擋）。

### 共同規則

- 每次朗讀有序號；新的朗讀開始後，舊朗讀的所有計時器與事件一律忽略。
- 某引擎連續失敗 2 次，跳過它 2 分鐘後再試。
- 全部引擎都失敗時提示一次，並照常解鎖按鈕。同一種提示每次開啟只顯示一次。
- 朗讀前清理文字：英文把 sb、sth 念成 somebody、something，去掉 N.、V-ing、加號等，door(s) 念成 doors；中文去掉括號內容與刪節號。
- 慢速：內建語音 rate 0.75，Google 語音 playbackRate 0.75。

### 作答後的朗讀

每題作答後依序念英文、中文、例句。畫面頂端滑出字幕條，標示「英文／中文／例句」與正在念的文字。朗讀期間「下一題」鎖住並顯示「朗讀中…」，最長 25 秒後強制解鎖。使用者按任何喇叭會中斷這段朗讀。

## 6. 打怪模式

回合制：答對得能量並選招式，答錯被怪物攻擊，打倒 5 隻怪物破關。玩家 HP 100，能量上限 40。

### 回合流程

1. 按「下一題」才出題並開始 10 秒計時條（只影響能量，不會超時）。
2. 答對：獲得能量 `max(1, min(10, round(10 − 作答秒數)))`；題目與答案留在畫面，招式選單疊在戰鬥畫面上。
3. 選招式（或「不出招」保留能量）→ 播動畫 → 回到步驟 1。
4. 答錯：怪物攻擊，傷害為該怪物攻擊力加 0–6 的亂數；該字插回 3 題後再考（最多 3 次）。
5. 連續答對加成：傷害乘以 `1 + min(0.5, 0.1 × (連擊數 − 1))`。
6. 打倒怪物回復 25 HP，下一隻進場。

### 其他

- 第一次戰鬥前播 5 句序章（劍與魔法的大陸艾爾文斯，史萊姆魔王偷走詞語之力），可點畫面繼續或按「跳過序章」，看過後不再出現。

- 結束畫面顯示打倒數、答對數、最高連擊、最快秒數與這場答錯的字。

## 7. 魂系模式

即時制：玩家回合有 10 秒攻擊時間累積 ATB 出招，敵人回合靠答題閃避。怪物、HP 與連擊加成同打怪模式，不使用能量。

### 玩家回合

- 攻擊時間 10 秒，只在題目顯示中倒數；朗讀、指令選單、招式動畫期間暫停。
- 每答對一題 ATB +1（上限 3）；答錯不受傷，只損失時間。
- 每次作答後開啟指令選單，畫面進入慢動作。
- 時間用完後進入敵人回合。

| 指令 | ATB | 傷害 |
| --- | --- | --- |
| 斬擊 | 1 | 12 |
| 疾風連斬 | 2 | 11, 11, 14（合計 36） |
| 大招（依第幾隻怪物輪替） | 3 | 雷霆之矛 72、冰晶風暴 82、流星斬 84、火球術 76、聖光審判劍 115 |
| 繼續答題／結束攻擊 | 0 | 保留 ATB |

### 敵人回合

- 攻擊次數：第 1–2 隻 1 次，第 3–4 隻 2 次，魔王 3 次。
- 每次攻擊：怪物先蓄力（紅色「！」與紅色集中線），再出一題紅框閃避題。
- 閃避限時：一般 4 秒，第 4 隻起 3.5 秒，魔王 3 秒。
- 答對：主角側閃、怪物撲空。1.5 秒內答對為「完美閃避」：慢動作、ATB +1、自動反擊 10 點。
- 答錯或超時：受到該怪物的攻擊傷害。
- 閃避題一律是選擇題；填空題型會改用對應的選擇題型。

### 時間減速

全域時間倍率 TS 除以所有動畫長度、乘以粒子更新時間。指令選單開啟時畫面降飽和度並加藍色暈影、角色待機動畫放慢。大招 TS 0.6、小招 0.85、完美閃避 0.45、反擊 0.7。

鍵盤：1–4 作答，1、2、3 出招，0 或 Enter 繼續。

## 8. 美術、動畫、音效與配樂

戰鬥畫面是明亮的日式 RPG 風格加漫畫式打擊特效，所有動畫只用 transform 與 opacity。

### 圖片（內嵌 base64 WebP）

| 素材 | 內容 | 尺寸 |
| --- | --- | --- |

### 戰鬥畫面配置

- 怪物在右上、主角在左下，各有地面陰影；怪物有上下漂浮的待機動畫，主角有呼吸動畫。

- 黑色粗框與硬陰影的漫畫格外框。

### 動畫手法

| 手法 | 做法 |
| --- | --- |
| 角色移動 | Web Animations API，只動 transform 與 opacity |
| 粒子層 | 一張 canvas，單一 requestAnimationFrame 迴圈：墨點、弧形斬痕、衝擊環、集中線、閃電、全畫面閃光 |
| 頓格 | 命中瞬間暫停角色動畫 50–160 毫秒 |
| 衝擊格 | 大招命中時全畫面黑底白色放射線 70–130 毫秒 |
| 殘影 | 衝刺時每 34 毫秒複製一個灰色分身並淡出 |
| 擬聲字 | 「斬！」「轟隆！！」等粗黑字白邊，放大彈出後上飄淡出；傷害數字橘紅色 |
| 特寫 | 大招前黑色斜帶橫切畫面，顯示主角與招式名 |
| 魔法陣 | 施法時腳下出現旋轉的六芒星 SVG 圓陣 |
| 畫面震動 | 依威力隨機位移 7 格，約 340 毫秒 |

各招式：斬擊為蓄勢、衝刺、斬；連斬為三道交叉斬痕；火球為魔法陣後火球飛行爆炸；雷霆為特寫、天色轉暗、兩道閃電；冰暴為冰晶落下五連擊；流星斬為躍起俯衝；聖光劍為巨大光劍從天而降。尊重 `prefers-reduced-motion`。

### 3D 戰鬥畫面（Three.js，`src/battle/view3d/`）

戰鬥畫面中間的 `#arena` 由 `src/battle/view3d.js` 掛載；上面幾節描述的 2D 圖片版是原始設計，現行實作是 3D：

- three.js 只在進入戰鬥時動態載入（`view3d/scene.js` 獨立成一個 chunk）；WebGL 不可用或啟動失敗時退回 `view3d/textview.js` 的文字畫面。
- 打怪模式（`monsterScene.js`）：明亮草原、卡通漸層材質＋描邊、彈性動作、星星／擬聲字／彈跳傷害數字。主角在畫面左下、怪物在右上。
- 魂系模式（`soulScene.js`）：廢墟教堂圓形競技場、FogExp2 濃霧、火盆點光源、月光與陰影、餘燼；鏡頭在主角右後方鎖定 Boss。
- 模型放在 `public/models/<代號>.glb`（臉朝 +Z、原點在腳底）。清單由 `vite.config.js` 的 `virtual:model-list` 在建置時讀取；沒有的模型用 `standins.js` 的程式替身，缺的動作用 `actors.js` 的補間動作（PROC）。
- 效能：DPR 上限 2，連續掉幀先降到 1、再關陰影與環境反射；頁面隱藏時暫停；`prefers-reduced-motion` 時關閉震動、頓格、閃光與鏡頭推拉並減少粒子。
- `#arena` 的 `data-fps`／`data-dpr`／`data-quality` 每秒更新一次，方便檢查效能。

### 音效與配樂（Web Audio 合成，無音檔）

- 音效：出招（方波上滑）、命中（雜訊＋低頻）、重擊、受傷、倒下、勝利、失敗。
- 配樂：C 大調，每步 0.2 秒，64 步循環；方波主旋律、三角波低音、雜訊 hi-hat、正弦大鼓（打怪模式）。魂系模式另有一首 A 小調、每步 0.5 秒的慢速配樂：低八度三角波旋律、正弦長音低音與五度墊底、緩慢低鼓。音量 0.045，朗讀時降到 0.012。可用按鈕開關。

## 9. 重建步驟與驗收清單

最快的複製方式是直接複製 `單字剪卡.html`：它就是完整原始碼，改檔名即可部署。要從頭重寫時，建議依下列順序。

1. 骨架：hash 路由、儲存、內建字典、字典頁與編輯。
2. 五種題型與判分、錯題重出、錯題紀錄頁。
3. 朗讀系統（先內建語音，再加 Google 備援與字幕）。
4. 掃描（透視校正、去陰影）、提取、核對。
5. 打怪模式：畫面配置、回合流程、招式動畫、連招。
6. 魂系模式、配樂。

### 驗收清單

- [ ] 用 Chrome 直接開啟檔案即可使用，內建字典 128 筆。
- [ ] 五種題型都能作答；輸入「喜好」答 love 這類近義答案算對。
- [ ] 答錯的題目在本輪稍後重出，並出現在錯題紀錄。
- [ ] 每題作答後依序念英文、中文、例句，頂端有字幕；快速連續作答也不漏念。
- [ ] 關掉網路仍能練習與朗讀（裝置語音）。
- [ ] 掃描一張單字頁：可調四角、拉平、提取，故意改錯中文會出現紅框警告。
- [ ] 戰鬥畫面在 390×700 的手機畫面不需捲動，4 個選項全部可見。
- [ ] 打怪：能量、招式扣能量、三種連招要全部答對才發動、答錯中斷。
- [ ] 魂系：10 秒攻擊時間、ATB、指令慢動作、閃避與完美閃避反擊。
- [ ] 匯出備份後清除資料，再匯入可完整還原。

### 已知限制

- Google 翻譯語音與翻譯是非官方端點，可能被限流或停用；正式上線建議改用 Google Cloud Text-to-Speech 或預錄音檔。
- 資料只存在單一瀏覽器，不跨裝置同步。
- API 金鑰存在瀏覽器，只適合個人使用；多人使用需改由後端代呼叫。
- 三隻怪物是換色版，尚無獨立美術；角色動畫是單張圖的位移與旋轉，沒有逐格動作。
